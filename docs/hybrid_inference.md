# BC 混合推理

实战配置设置 `device: hybrid`，或在网页参数与记录的推理设备中填写 hybrid，暂停后应用并重新加载。原 CPU/CUDA 模式和默认配置保持不变。

CPU：状态 embedding、当前状态编码、对象编码、融合与分类输出；CUDA:0：TCN 及其逐层缓存。新增状态特征上传到 GPU，最后一个256D时序特征返回 CPU。GPU 提交之后先运行 CPU 的当前状态/对象分支，再回传等待；不承诺一定实现完全重叠。

`amp: true` 时仅 CUDA 算子启用 FP16 autocast，CPU 分支仍 FP32，回传转换为 CPU 当前特征的 dtype。没有 CUDA 时明确报错，不静默退回 CPU。模型参数和训练 checkpoint 格式不变，切换模式重建会话与缓存。

耗时表增加 TCN 特征上传、TCN 特征回传/等待。TCN 主机时间主要反映提交，异步计算的剩余等待可能出现在回传阶段；不要只比较 TCN 主机耗时判断加速。CUDA 时间线也包含 CPU 空隙。应对比总推理 P50/P95、相同新计算帧数，并分开稳态与重建。
