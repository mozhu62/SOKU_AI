# BC TCN256

默认 `configs/bc_suika.yaml` 已改为 `model.temporal_mode: tcn256`、`training.burn_in: 255`。新网络版本是 `soku_bc_tcn256_joint144_v1`。旧 `tcn` 模式明确保留32帧语义，旧模型不被伪装为256帧。

七个双卷积块采用膨胀率 `[1,2,4,8,16,32,64]`，卷积核2、步长1，加上起始卷积得到256帧感受野。窗口包括当前及前255帧，60FPS约4.25秒历史跨度。228D输入、通道宽度、每侧3个当前对象、Joint144、CE、关键帧加权及PALR均保持原配置。没有引入IQL、N-step或奖励。

监督段仍32，完整训练序列为255+32=287帧。历史不足时mask处理，不跨片段/回合，不给当前标签泄漏未来。随机独立实验沿用当前窗口，不再强制退回32帧。旧TCN32配置及PALR A/B/C/D文件保留原规格，以免已有对照实验被静默改变。

## 随机初始化训练

```powershell
python scripts/train.py --config configs/bc_suika.yaml --start
```

新输出为 `outputs/bc_suika_tcn256_joint144`，旧目录不覆盖。沿用现有NPZ和固定划分，无需重新录制。

## 可选：显式迁移旧BC

```powershell
python scripts/migrate_tcn256.py --source outputs/bc_suika_tcn32_joint144/last.pt --output outputs/bc_suika_tcn256_joint144/initial.pt
python scripts/train.py --config configs/bc_suika.yaml --resume outputs/bc_suika_tcn256_joint144/initial.pt --start
```

source替换为实际旧BC路径。复用全部旧层，仅新增三个TCN块随机初始化；优化器、计数、排名重置，不保证原策略输出不变。归一化和固定划分hash保留，启动时继续校验；目标文件存在时拒绝覆盖。CPU迁移包的空AMP状态在CUDA恢复时新建缩放器，不再直接加载空字典。

## 实战

```powershell
npm --prefix web run build
python scripts/play.py --config configs/live_eval.yaml
```

实战默认加载新目录last.pt，网页也可选择模型。窗口按模型32/256规格动态选择，必须积累满真实连续帧才发键；断帧或换局重置。256帧初始积累约4.3秒。DLL128槽是传输缓存，Python持续消费并维护独立256帧历史，无需改变DLL结构；读取太慢仍可能覆盖槽并重置。

本次没有增加逐层推理缓存，训练显存和推理开销会增大。原32帧BC可以在本项目加载，未更新的旧程序会拒绝256版本。IQL项目未改。
